# Settings - Customizing Your Experience

## TL;DR
Adjust font size for easier reading and view theme settings. Changes apply immediately across the entire app.

## Font Size

### Available Options
Two font size settings designed for readability:

**Normal (1.0x)**
- Standard text size
- Default setting
- Good for most users

**Large (1.15x)**
- 15% larger text
- Easier reading for low vision
- Recommended for elderly users
- All text scales proportionally

### How to Change
1. Go to Settings tab (⚙️ icon in bottom nav)
2. Look for "Font Size" section
3. Select your preference:
   - Tap the radio button next to "Normal" or "Large"
4. Changes apply **immediately** across all screens

### What Changes
Font size affects:
- All text content (medication names, dosages, times)
- Button labels
- Headers and titles
- Statistics and percentages
- Navigation labels

### What Stays the Same
- Touch target sizes (always ≥48dp)
- Icon sizes
- Button dimensions
- Spacing and padding

## Theme

### System Theme
- App follows your device's light/dark mode setting
- Automatically switches when your phone theme changes
- No manual toggle needed

### Light Mode
- Clean white backgrounds
- High contrast text
- Soothing blue primary color
- Material 3 light palette

### Dark Mode
- Dark backgrounds to reduce eye strain
- Adjusted colors for readability
- Same calm blue theme
- Material 3 dark palette

### Dynamic Colors (Android 12+)
- On compatible devices, colors adapt to your wallpaper
- Maintains accessibility and contrast
- Personalized while staying readable

## Accessibility Features

### Built-in Design
The app includes accessibility features by default:

**Large Touch Targets**
- All buttons and interactive elements ≥48dp
- Easy to tap accurately
- Reduces mis-taps

**Color Contrast**
- High contrast between text and backgrounds
- Material 3 ensures WCAG compliance
- Works in both light and dark modes

**Calm Color Palette**
- Soothing blue theme reduces anxiety
- Not harsh or alarming
- Gentle on the eyes

**Non-Judgmental Language**
- "Missed" instead of "Failed"
- Encouraging feedback
- Positive reinforcement

## Reset to Defaults

### How to Reset
To return to default settings:
1. Select "Normal" font size
2. Ensure device is in light mode (if preferred)

All settings stored locally - no cloud sync.

## Tips

### Best Font Size for You
- Try both settings for a day
- Large is great for reading across the room
- Normal works well for close-up viewing
- You can change anytime without losing data

### Theme Recommendations
- Use dark mode in evening to reduce eye strain
- Light mode during day for better outdoor visibility
- Let system handle it automatically based on time

### Sharing Settings
If multiple people use the app on one device:
- Settings apply to the entire app
- Choose the font size that works for the primary user
- Consider the Large option for elderly users
